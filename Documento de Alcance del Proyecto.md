# **Documento de Alcance del Proyecto**

## **1\. Nombre del proyecto**

**Portal web de búsqueda, ofertas, noticias laborales, prácticas profesionalizantes, pasantías y primeras experiencias laborales para una consultora RRHH Tech.**

## **2\. Descripción general**

El proyecto consiste en desarrollar un **Sistema de Información Web** destinado a organizar, publicar y consultar información relacionada con oportunidades laborales y formativas.

El portal no será solamente una página web informativa, sino un sistema que permitirá gestionar distintos tipos de contenidos y oportunidades, usando tecnologías web, formularios, navegación, base de datos, usuarios y procesos internos.

## **3\. Objetivo general**

Desarrollar un portal web que permita centralizar información sobre ofertas laborales, noticias laborales, prácticas profesionalizantes, pasantías y primeras experiencias laborales, facilitando la consulta y organización de oportunidades para los usuarios.

## **4\. Objetivos específicos**

* Publicar ofertas laborales de manera ordenada.  
* Mostrar noticias laborales relevantes.  
* Organizar prácticas profesionalizantes.  
* Organizar pasantías.  
* Incluir primeras experiencias laborales.  
* Diferenciar los tipos de oportunidades según sus características.  
* Permitir la consulta clara de información desde un navegador.  
* Preparar una base para futuras funciones como postulaciones, perfiles de usuario, comunidad o formación.  
* Documentar el proceso de trabajo mediante bitácoras y registros del proyecto.

## **5\. Alcance incluido**

El sistema incluirá inicialmente:

### **5.1 Oportunidades laborales y formativas**

El portal contempla los siguientes tipos de oportunidades:

* Ofertas laborales.  
* Noticias laborales.  
* Prácticas profesionalizantes.  
* Pasantías.  
* Primeras experiencias laborales.

Las prácticas profesionalizantes podrán ser remuneradas o no remuneradas, e incluir o no viáticos.  
Las pasantías también podrán ser remuneradas o no remuneradas, e incluir o no viáticos.  
Las primeras experiencias laborales se considerarán remuneradas obligatoriamente dentro del modelo del proyecto.

### **5.2 Gestión de contenidos**

El sistema permitirá trabajar con contenidos relacionados con el mundo laboral, por ejemplo:

* Publicar información.  
* Organizar contenidos.  
* Actualizar noticias y oportunidades.  
* Consultar información de forma ordenada.

### **5.3 Componentes web básicos**

El portal podrá incluir:

* Páginas web.  
* Formularios.  
* Menús de navegación.  
* Base de datos.  
* Usuarios.  
* Procesos internos.  
* Resultados visibles desde un navegador.

### **5.4 Organización del trabajo**

El desarrollo del proyecto se organizará mediante:

* Macrogrupos.  
* Células de trabajo.  
* Perfiles IT principales.  
* Perfiles IT secundarios.  
* Roles iniciales.  
* Bitácora personal o grupal del proyecto.

## **6\. Alcance no incluido en la etapa inicial**

En esta primera etapa no se incluye:

* Un sistema completo de contratación laboral real.  
* Pagos dentro del portal.  
* Validación legal de contratos o pasantías.  
* Integraciones externas con empresas reales.  
* Automatización completa de selección de candidatos.  
* Desarrollo definitivo de todas las funciones avanzadas.  
* Operación continua del portal una vez terminado.  
* Sprints formales desde el inicio, ya que primero se trabaja una fase preparatoria.

Estas funciones podrían analizarse en etapas futuras, cuando el proyecto avance en planificación, diseño, desarrollo e integración.

## **7\. Usuarios o actores principales**

Los posibles usuarios del sistema serán:

* **Postulantes o estudiantes:** consultan oportunidades laborales, prácticas, pasantías y primeras experiencias.  
* **Consultora RRHH Tech:** administra, pública y organiza contenidos.  
* **Empresas u organizaciones:** podrían ofrecer oportunidades en futuras etapas.  
* **Equipo de desarrollo:** diseña, construye, prueba y documenta el sistema.  
* **Docentes o responsables del proyecto:** orientan, revisan y acompañan el proceso.

## **8\. Entregables esperados**

Durante el desarrollo del proyecto se podrán producir los siguientes entregables:

* Documento de alcance del proyecto.  
* Organización inicial de macrogrupos y células.  
* Definición de perfiles IT.  
* Relevamiento inicial de necesidades.  
* Prototipos o bocetos del portal.  
* Modelo inicial de datos.  
* Versión funcional del sistema web.  
* Documentación técnica y funcional.  
* Pruebas del sistema.  
* Presentación final del proyecto.

## **9\. Metodología de trabajo**

El proyecto comenzará con fases preparatorias, donde se busca comprender el tipo de sistema, organizar el trabajo humano y definir mejor el alcance.

Luego, el desarrollo podrá avanzar con una lógica más organizada, incorporando planificación, ciclo de vida del sistema, metodologías de desarrollo y eventualmente sprints o iteraciones de trabajo.

La idea principal es evitar la improvisación y construir el sistema de forma progresiva, documentada y ordenada.

## **10\. Supuestos del proyecto**

Para este alcance se parte de los siguientes supuestos:

* El portal será desarrollado como sistema web.  
* El proyecto tendrá una finalidad educativa e integradora.  
* El equipo trabajará dividido en macrogrupos y células.  
* Las funcionalidades se incorporarán de forma gradual.  
* La documentación será parte del proceso, no algo separado del desarrollo.  
* El sistema podrá evolucionar en módulos posteriores.

## **11\. Restricciones iniciales**

El proyecto tendrá algunas restricciones:

* Tiempo limitado de cursada.  
* Organización inicial todavía provisoria.  
* Funciones avanzadas pendientes de definición.  
* Necesidad de coordinar varios perfiles y células de trabajo.  
* Alcance educativo, no comercial completo desde el inicio.  
* Dependencia de futuras decisiones sobre diseño, base de datos, roles y tecnología.

## **12\. Criterios de aceptación iniciales**

El proyecto podrá considerarse correctamente encaminado si:

* Se entiende que el sistema no es solo una página web, sino un Sistema de Información Web.  
* El alcance inicial queda claramente definido.  
* Se diferencian los tipos de oportunidades del portal.  
* Se identifican los usuarios principales.  
* Se organizan macrogrupos y células de trabajo.  
* Se documentan decisiones, dudas y avances en la bitácora.  
* Se prepara una base clara para pasar a etapas posteriores de análisis, diseño, desarrollo y prueba.

## **13\. Conclusión**

El alcance inicial del proyecto define la construcción de un portal web para una consultora RRHH Tech, orientado a la búsqueda, publicación y organización de oportunidades laborales y formativas.

El sistema deberá permitir gestionar información sobre ofertas laborales, noticias, prácticas profesionalizantes, pasantías y primeras experiencias laborales. Además, servirá como proyecto integrador para aplicar conceptos de sistemas de información, ingeniería de software, planificación, roles IT y trabajo organizado por células.
